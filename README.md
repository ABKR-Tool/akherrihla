## العب اللعبة

[افتح اللعبة عبر GitHub Pages](https://ABKR-Tool.github.io/akherrihla/) — قد يستغرق أول نشر بضع دقائق.

نسخة الويب المنشورة موجودة في `docs/`، ومصدر Godot والأصول المستخدمة في بقية المستودع.

هذا مستودع عام للعرض والتشغيل. **لا يتضمن الكود رخصة إعادة استخدام**؛ لا تفترض أن الإتاحة العامة تمنح حق النسخ أو التعديل أو إعادة التوزيع.

# آخر رحلة

لعبة مغامرة قصصية تفاعلية ثنائية الأبعاد باللغة العربية، مبنية بمحرك Godot. تبدأ من طائرة تغادر السعودية، ثم يختار اللاعب وجهة الهبوط الاضطراري: مصر أو المغرب أو تشاد. تغيّر القرارات موارد الناجي وعلاقاته والطريق الذي يسلكه، والهدف هو بلوغ طائرة في تشاد.

## التشغيل محليًا

**المتطلبات:** Godot 4.7 أو أحدث، مع قوالب التصدير المناسبة إذا رغبت في بناء نسخة الويب.

1. افتح `project.godot` في Godot، أو شغّل المشروع من الطرفية:

   ```sh
   godot --path .
   ```

2. اختر الاسم والبلد، ثم استخدم أزرار الخيارات. تعمل الواجهة باللمس والفأرة ولوحة المفاتيح؛ `Tab` للتنقل بين الأزرار، و`Enter` للتفعيل، و`Esc` لإيقاف الرحلة أو استئنافها.
3. التقدم مؤقت في ذاكرة الجلسة فقط. لا توجد حسابات أو قاعدة بيانات أو حفظ محلي/سحابي؛ إعادة التشغيل أو إغلاق الصفحة يبدأ من جديد.

## تصدير نسخة الويب

قالب Godot المسمى `Web` مضبوط على إخراج اللعبة إلى `dist/index.html`، مع حزمة WebAssembly والموارد اللازمة. بعد تثبيت قالب تصدير الويب من Godot:

```sh
mkdir -p dist
godot --headless --path . --export-release "Web"
```

شغّل مجلد `dist` عبر خادم HTTP محلي؛ لا تفتح `index.html` مباشرة بصيغة `file://` لأن المتصفح يقيّد تحميل WebAssembly والموارد:

```sh
cd dist
python3 -m http.server 8000 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:8000`. متطلبات التصدير وتفاصيله تتغير حسب نسخة Godot، وقد يلزم تنزيل قالب Web المطابق لنسخة المحرك.

## الاختبارات

من داخل بيئة Manus المهيأة للمشروع:

```sh
npm run check
npm run check -- --pack
```

يشغّل الاختبار الأول فحصًا محدودًا للمشاهد والاختيارات والموارد ونهايات المسارات الثلاثة، ويشغّل الثاني فحص حزمة التصدير الحالية. محليًا، يمكنك فتح مشهد الاختبار `res://test/test_suite.tscn` من المحرر بعد استيراد الموارد.

## محتويات المشروع

- `scripts/main.gd`: واجهة البداية والحالة والمشهد والاختيارات والإيقاف وإعادة اللعب.
- `scripts/story_engine.gd`: محرك مستقل للانتقالات والشروط والموارد والرفاق.
- `data/story_ar.json`: النصوص والمشاهد ومسارات مصر والمغرب وتشاد والنهايات.
- `assets/story/runtime/`: خلفيات خفيفة مضمّنة في اللعبة.
- `assets/source-art/`: النسخ الأصلية عالية الدقة، مستبعدة من استيراد Godot بواسطة `.gdignore`.
- `assets/fonts/`: خط عربي مضمّن ونص رخصته.
- `assets/share/`: صورة المشاركة وأيقونة اللعبة.
- `ASSET_LICENSES.md`: بيان مصدر وترخيص الأصول.

## توسيع القصة

أضف مشهدًا في `data/story_ar.json` ثم اربط به اختيارًا باستخدام `next` أو `next_by_country`. صيغ البيانات الأساسية:

- `title`, `location`, `speaker`, `text`, `background`: عرض المشهد.
- `choices[].text`: نص الاختيار الظاهر.
- `choices[].requires`: شروط مثل `flag`, `water_min` أو `companion` لإظهار الاختيار.
- `choices[].effects`: تغييرات `health`, `water`, `food`, `trust`, `days`، وإضافة/إزالة رفيق أو ضبط علم قصة.
- `choices[].next_by_country`: وجهة مختلفة بحسب بلد الهبوط.
- `kind: "ending"`: علامة مشهد النهاية.

يستهلك الناجي الماء كل يومٍ ثانٍ والطعام كل يومٍ ثالث؛ إن نفد أحدهما مع مرور الأيام تتأثر صحته. الحد الأقصى للصحة 3، وللماء والطعام 5.
